# Curvy Blocks

Minecraft **1.21.1 / NeoForge 21.1.251 / Java 21** 的独立弯曲建筑模组。全部使用 Java，不依赖 Curvy Pipes、AE2、Rust 或 JNI。

副手持任意 `BlockItem`，即可用该方块的材质放置平滑曲线。支持原版和模组方块的方块图集贴图、着色与透明材质；没有普通面模型的方块使用其粒子贴图。曲线属于装饰建筑结构，不继承箱子库存、机器逻辑、红石或管道物流功能。

## 操作

默认开启弯曲放置模式。把方块放进副手，右键选择起点，移动准星后再次右键完成。

选点使用始终朝向视角的圆环，每个渲染帧跟随相机位置更新，并对网格吸附的小幅跳动做平滑过渡。已确认的节点显示为较小的圆环。

| 操作 | 功能 |
| --- | --- |
| 右键 | 选择起点／确认放置 |
| 潜行键＋右键 | 添加中间节点，继续编辑 |
| Enter | 完成当前预览 |
| 左键／Backspace（编辑中） | 撤销最后一个节点 |
| X | 取消当前草稿 |
| 左键瞄准已放置曲线 | 拆除整条曲线 |
| R | 切换 1/8、1/4、1/2、1 格粗细 |
| V | 切换圆形／方形截面 |
| G | 切换关闭、1/16、1/4、1/2 格吸附 |
| 按住疾跑键 | 忽略方块和曲线，在空中选点 |
| 按住左 Alt | 为受阻的曲线自动寻找绕障路径 |
| Alt＋滚轮 | 调整空中选点距离，受原版交互距离限制 |
| B | 开关弯曲模式；关闭后恢复普通副手操作 |

自定义快捷键可以在游戏的按键设置中修改。瞄准曲线端点可以接续放置；瞄准中段创建分支时，连接点自动吸附到主干中心线，根部嵌入主干，并沿接触面的外法线出入，避免粗截面只在表面相切而露出缝隙。分支末端接入已有曲线时使用相同规则。中间节点之间平滑插值，附着在普通方块表面的端点沿表面法线出入。

按住左 Alt 时，受阻的曲线会直接进行连续拱形变形：优先向上拱起，空间不足时尝试侧向拱出，并在碰撞允许的范围内压低拱高。拱顶可以偏向障碍所在位置，短距离拱起时会自动舒展两侧转弯。手动节点、端点位置和连接切线保持原样，自动避障只保存每段的拱起方向、高度和拱顶位置。

拱形直接参与网格生成、实体碰撞、光照采样、拾取、材料计算和存档同步。试算会考虑方块实际碰撞形状、曲线粗细和 `no_overlap` 标签，并校验整条变形后的曲线。

试算期间右键确认会锁定终点，得到可放置拱形后自动提交；X 可以取消。松开左 Alt 后恢复手动预览，已经确认的试算会继续完成。试算分摊到多个 tick，偏移范围或试算次数不足时显示失败提示。最终仍由服务端复核碰撞、权限和材料，材料消耗按拱起后的实际长度计算。

## 材料与世界数据

- 生存模式消耗 `向上取整（曲线长度 × 截面积 × 材料倍率）` 个方块，至少消耗一个。按选中槽、主背包、副手的顺序扣除，物品组件必须相同。
- 生存模式拆除返还该曲线实际消耗的材料，背包放不下则掉落。创造模式免费，免费放置的曲线不会生成返还物品。
- 曲线按维度保存在 `data/curvyblocks.dat` 中，并按玩家已接收的区块同步。跨区块曲线会保留到最后一个相关区块卸载。
- 默认检查建筑高度、世界边界、加载区块、玩家权限、实体及方块遮挡。实体碰撞使用缓存的分段 AABB，与圆形表面可能有少量偏差。
- 曲线之间允许重叠，以便制作接头和分支；每条曲线独立保存、独立拆除。
- 使用 NeoForge 事件处理输入、渲染和区块同步；仅在 `EntityGetter#getEntityCollisions` 使用一个 Mixin，追加实体碰撞形状。

曲线不占用原版方块格子，也不创建方块实体。领地或其他权限模组可订阅可取消的 `com.lirxowo.curvyblocks.api.CurveEditEvent`，通过 `getPlayer()`、`getCurve()` 和 `isRemoval()` 检查编辑操作。

## 配置

进入世界后生成 `<世界目录>/serverconfig/curvyblocks-server.toml`，NeoForge 会同步服务端配置。

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `maxLength` | 64 | 单条曲线最大长度 |
| `placementRange` | 32 | 提交时每个节点到玩家的最大距离 |
| `materialMultiplier` | 1 | 材料消耗倍率 |
| `maxCurvesPerChunk` | 256 | 每区块曲线数量上限 |
| `allowBlockOverlap` | false | 允许与普通方块重叠 |
| `solidCurves` | true | 曲线参与实体碰撞 |
| `ownerOnlyRemoval` | false | 仅放置者和管理员可拆除 |
| `autoRouteSearchMargin` | 4 | 每段自动拱起的最大偏移 |
| `autoRouteMaxCandidates` | 96 | 单次自动避障最多试算的拱形数量 |

`curvyblocks:no_overlap` 方块标签始终禁止曲线穿过。数据包可以扩充此标签。

## 构建

在 Java 21 环境中运行 `gradlew.bat build`，产物位于 `build/libs/`。客户端与服务端均需安装。

连续拱形使用协议版本 2，客户端与服务端需要一起更新。旧存档中的曲线可以继续读取；旧式自动拐点保持原状，重新放置时会使用连续拱形避障。

`libs/` 与 `reverse-engineering/` 中保留的参考资料不会参与编译或打包。
