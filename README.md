# Curvy Blocks

Minecraft **1.21.1 / NeoForge 21.1.251 / Java 21** 的独立弯曲建筑模组。全部使用 Java，不依赖 Curvy Pipes、AE2、Rust 或 JNI。

副手持任意 `BlockItem`，即可用该方块的材质放置平滑曲线。支持原版和模组方块的方块图集贴图、着色与透明材质；没有普通面模型的方块使用其粒子贴图。曲线会读取原方块的移动与接触属性；箱子库存、机器逻辑、红石或管道物流功能不属于材质属性。

## 操作

默认开启弯曲放置模式。把方块放进副手，右键选择起点，移动准星后再次右键完成。

选点使用始终朝向视角的圆环，每个渲染帧跟随相机位置更新，并对网格吸附的小幅跳动做平滑过渡。已确认的节点显示为较小的圆环。

曲线预览使用连续的半透明外表面，保留材质贴图和放置状态颜色。绘制时先确定最近可见表面的深度，再为该表面着色，避免前后表面按采样段重复混色而产生切片状条带。

| 操作 | 功能 |
| --- | --- |
| 右键 | 选择起点／确认放置 |
| 潜行键＋右键 | 添加中间节点，继续编辑 |
| Enter | 完成当前预览 |
| 左键／Backspace（编辑中） | 撤销最后一个节点 |
| X | 取消当前草稿 |
| 左键瞄准已放置曲线 | 拆除整条曲线 |
| 鼠标中键／原版「选取方块」按键 | 选取准星命中曲线的原方块材质 |
| R | 切换 1/8、1/4、1/2、1 格粗细 |
| V | 切换圆形／方形截面 |
| G | 切换关闭、1/16、1/4、1/2 格吸附 |
| 按住疾跑键 | 忽略方块和曲线，在空中选点 |
| 按住左 Alt | 为受阻的曲线自动寻找绕障路径 |
| Alt＋滚轮 | 调整空中选点距离，受原版交互距离限制 |
| B | 开关弯曲模式；关闭后恢复普通副手操作 |

自定义快捷键可以在游戏的按键设置中修改。瞄准曲线端点可以接续放置；瞄准中段创建分支时，连接点自动吸附到主干中心线，根部嵌入主干，并沿接触面的外法线出入，避免粗截面只在表面相切而露出缝隙。分支末端接入已有曲线时使用相同规则。中间节点之间平滑插值，附着在普通方块表面的端点沿表面法线出入。

只有主干和分支都为圆形截面，且分支接在主干曲线中段时，才生成球状绳结，使用主干的方块材质、着色与透明类型。主干的起点和终点接续不生成球节，也不参与球节尺寸计算；这一规则同时适用于预览、已放置曲线和旧存档接头识别。任意一侧为方形时保留原来的连接方式，方形曲线不参与球节生成或尺寸计算。绳结按连接处最粗圆形截面的半径生成，并额外留出包边，遮住粗分支接入细主干时外露的根部。同一点的多个圆形中段分支会共用一个绳结，沿用最早圆形主干的材质，大小随中段分支更新。

预览中会同时显示绳结，曲线和绳结共用深度预绘制，避免连接处重复叠加半透明表面。绳结属于外观接头，其碰撞沿用曲线本体的分段 AABB。瞄准绳结可以从该节点继续分支，也可以中键选取主干材质；拆除其最后一条分支或主干后，对应绳结自动移除。连接引用会随曲线存档和同步；旧存档根据节点与较早曲线中心线的连接关系识别已有接头。

中键选取也支持背后没有普通方块的悬空曲线，遵守原版交互距离和前方方块、实体的遮挡。创造模式将材质选入快捷栏；生存模式只选取背包中已有的相同物品，背包内的换槽由服务器处理。此操作不需要开启弯曲模式或副手持方块，选取后可用原版交换主副手按键将材料放入副手。

按住左 Alt 时，受阻的曲线会直接进行连续拱形变形：优先向上拱起，空间不足时尝试侧向拱出，并在碰撞允许的范围内压低拱高。拱顶可以偏向障碍所在位置，短距离拱起时会自动舒展两侧转弯。手动节点、端点位置和连接切线保持原样，自动避障只保存每段的拱起方向、高度和拱顶位置。

拱形直接参与网格生成、实体碰撞、光照采样、拾取、材料计算和存档同步。试算会考虑方块实际碰撞形状、曲线粗细和 `no_overlap` 标签，并校验整条变形后的曲线。

试算期间右键确认会锁定终点，得到可放置拱形后自动提交；X 可以取消。松开左 Alt 后恢复手动预览，已经确认的试算会继续完成。试算分摊到多个 tick，偏移范围或试算次数不足时显示失败提示。最终仍由服务端复核碰撞、权限和材料，材料消耗按拱起后的实际长度计算。

## 材料与世界数据

- 生存模式消耗 `向上取整（曲线长度 × 截面积 × 材料倍率）` 个方块，至少消耗一个。按选中槽、主背包、副手的顺序扣除，物品组件必须相同。
- 生存模式拆除返还该曲线实际消耗的材料，背包放不下则掉落。创造模式免费，免费放置的曲线不会生成返还物品。
- 曲线编辑时，客户端与服务端共同接管右键，阻止原版方块放置及预扣物品。扣料和返还在操作确认前同步；按住的一次右键持续接管到松开。
- 曲线按维度保存在 `data/curvyblocks.dat` 中，并按玩家已接收的区块同步。跨区块曲线会保留到最后一个相关区块卸载。
- 默认检查建筑高度、世界边界、加载区块、玩家权限、实体及方块遮挡。实体碰撞使用缓存的分段 AABB，与圆形表面可能有少量偏差。
- 曲线之间允许重叠，以便制作接头和分支；每条曲线独立保存、独立拆除。
- 使用 NeoForge 事件处理输入、渲染和区块同步；通过 Mixin 追加曲线碰撞，并将实体脚下材质查询和接触回调接入曲线。

曲线不占用原版方块格子，也不创建方块实体。领地或其他权限模组可订阅可取消的 `com.lirxowo.curvyblocks.api.CurveEditEvent`，通过 `getPlayer()`、`getCurve()` 和 `isRemoval()` 检查编辑操作。

## 材质物理

默认根据实体实际接触的曲线读取材质，没有按方块 ID 设置白名单。原版方块和通过相同公开接口实现效果的模组方块使用同一套逻辑。

| 原方块接口 | 曲线上的效果与示例 |
| --- | --- |
| NeoForge `getFriction` | 继承摩擦系数，包括普通冰、浮冰、蓝冰和模组滑面；也接入掉落物与船的地面摩擦 |
| `getSpeedFactor` / `getJumpFactor` | 继承移速与跳跃倍率，例如灵魂沙减速、蜂蜜减速和降低跳跃高度 |
| `stepOn` | 继承踩踏效果，例如黏液减速、岩浆块伤害，并保留原回调中的潜行等判断 |
| `fallOn` / `updateEntityAfterFallOn` | 继承落地伤害计算、缓冲和反弹，例如干草、蜂蜜、床、黏液 |
| `entityInside` | 继承接触效果，例如蜘蛛网束缚、仙人掌或点燃营火的伤害、凋零玫瑰的药水效果 |
| `getSoundType` 和原版脚步逻辑 | 根据材质播放脚步声、落地声，并保留紫水晶等材质的特殊脚步效果 |
| `addRunningEffects` / `addLandingEffects` | 使用原方块的疾跑与落地粒子；支持对应的 NeoForge 自定义粒子接口 |

原方块声明 `noCollission` 时，曲线允许实体穿过并触发接触效果，因此蜘蛛网曲线不会成为普通实心管。其余曲线仍使用自己的分段碰撞形状。实体的脚下与接触材质查询会返回原方块状态，生物已有的移动效率属性继续参与速度计算。

踩踏和接触效果按实体、曲线与 tick 去重，不会因为一条曲线包含多个采样段而叠加。接触结果随实体位置、世界与曲线索引更新，客户端和服务端使用相同的接触判断。

声音触发频率和粒子生成条件沿用原版：正常行走播放脚步声，疾跑和符合条件的落地产生相应粒子。粒子读取曲线的真实材质和脚下位置，服务端落地粒子会按原版方式发送给附近玩家。

曲线没有原版格子和方块实体，因此依赖机器库存、邻居更新或修改真实方块的逻辑不会完整继承。转发的回调若尝试通过常规方块 API 放置、破坏、掉落或推动实体填补格子，会被中止并停用该材质的对应回调；其余属性继续生效，落地逻辑在尚未结算伤害时退回普通方块处理。异常的第三方回调会记录日志并单独停用。依赖原版立方体坐标的效果（例如蜂蜜侧面滑行）、直接查询世界格子的附魔条件，以及细雪、脚手架等随实体改变的碰撞规则，仍可能需要专门适配。

## 配置

进入世界后生成 `<世界目录>/serverconfig/curvyblocks-server.toml`，NeoForge 会同步服务端配置。

| 配置 | 默认值 | 用途 |
| --- | --- | --- |
| `maxLength` | 64 | 单条曲线最大长度 |
| `placementRange` | 32 | 提交时每个节点到玩家的最大距离 |
| `materialMultiplier` | 1 | 材料消耗倍率 |
| `maxCurvesPerChunk` | 256 | 每区块曲线数量上限 |
| `allowBlockOverlap` | false | 允许与普通方块重叠 |
| `solidCurves` | true | 曲线参与实体碰撞 |
| `materialEffects` | true | 继承原方块移动、落地与接触属性；关闭后恢复统一实心曲线 |
| `branchKnotScale` | 1.15 | 圆形曲线球节相对最大截面半径的倍率，范围 1.05～2 |
| `ownerOnlyRemoval` | false | 仅放置者和管理员可拆除 |
| `autoRouteSearchMargin` | 4 | 每段自动拱起的最大偏移 |
| `autoRouteMaxCandidates` | 96 | 单次自动避障最多试算的拱形数量 |

`curvyblocks:no_overlap` 方块标签始终禁止曲线穿过。数据包可以扩充此标签。

关闭 `solidCurves` 时，材质物理效果也会关闭，曲线仅用于显示。已有曲线会直接使用新的材质物理规则，无须重新放置。客户端与服务端需一起更新。

## 构建

在 Java 21 环境中运行 `gradlew.bat build`，产物位于 `build/libs/`。客户端与服务端均需安装。

分支连接引用使用协议版本 4，客户端与服务端需要一起更新。旧存档中的曲线可以继续读取；旧式自动拐点保持原状，重新放置时会使用连续拱形避障。

`libs/` 与 `reverse-engineering/` 中保留的参考资料不会参与编译或打包。
